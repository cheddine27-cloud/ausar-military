## 🇩🇿 الهيكل العسكري المدعوم

```
القائد العام (مديرية الخدمة الوطنية)
 └── قائد المركز / المعسكر
      └── قائد السرية
           └── العريف / الرقيب (مدوّن الحضور)
                └── الأفواج (فوج 1، فوج 2، ...)
```

### الفئات المستهدفة
| الفئة | الوصف |
|---|---|
| 🧢 **أشبال الأمة** | الشباب في الخدمة الوطنية |
| 🛡️ **الإدارات** | العسكريون الأداريون |
| 🎓 **العسكريون الدارسون** | العسكريون الذين يتابعون حصصاً دراسية |

## ⚙️ نظام الحضور والغياب

### الحصص
- 🌅 **حصة صباحية** — أدِر الحPresence الصباحي
- 🌙 **حصة مسائية** — أدِر الحضور المسائي
- 🎯 **تمرين تطبيقي**
- 📋 **مراقبة / اختبار**

### نموذج تدوين الحضور (كما يقيد به الرقيب)
```
فوج 1 — حصة صباحية          🪖
═══════════════════════════════
✅ حاضر:     27 عسكري
❌ غياب:      3 عسكريون
  ├─ 1  الأمانة (تدوين)
  ├─ 1  الخدمات
  └─ 1  مريض
```

### أسباب الغياب المدعومة
| السبب | يقبله الرقيب |
|---|---|
| 🏛️ الأمانة | مُندوب عمل في الأمانة |
| 🌿 الخدمات (البستان/النظافة) | مُكلَّف بخدمéries المصلحة |
| 🤒 مريض | إثبات طبي |
| 🚗 مأمورية خارجية | إعتماد القائد |
| ❓ بدون تبرير | تحتاج تدخل التبريرات |

### دورة اعتماد التقرير
```
مسودة (الرقيب) → في انتظار التدقيق (قائد السرية) → معتمد (قائد المركز)
                                      ↘ طلب تصحيح ← مرفوض
```

## ✨ الميزات

| الميزة | الوصف |
|---|---|
| ⚡ الحضور اليدوي | الرول كول السريع بالقائمة (الحضور/الغياب مع السبب) |
| 📱 الحضور الذكي | QR Code + بصمة الجهاز ضد الانتخاب المزيّف |
| 🌗 نظام صباحي/مسائي | حصتين في نفس اليوم لكل العسكريين المُدرسين |
| 🧾 التبريرات | تدوين سبب الغياب واعتماده رسمياً |
| 📄 التقارير | PDF/Excel لكل فوج يومياً، تفصيلياً، حسب الحصة (صباح)
| 📊]() الفلاشات لوحة تفاعلية (الملاك، نسب الغياب، الفلاشات) |
| 🔐 الأمان | أدوار، صلاحيات، سجل تدقيق، تصميم آمن مُعماري |
| 🔔 التنبيهات | تنبيه غياب متكرر، تقرير صباحي لقادة الثلاث |

## 🛠 التقنيات

| الطبقة | تقنية |
|---|---|
| الواجهة | React 18 + TypeScript + Vite |
| التصميم | Tailwind CSS + shadcn/ui (براندينغ عسكري) |
| قاعدة البيانات | Supabase (PostgreSQL + Row Level Security) |
| تطبيق الجوال | Flutter (طالب/عسكري — QR + Offline) |
| الفحص CI | GitHub Actions (Node + ESLint + Vite Build) |
| النشر | Vercel |

## 🚀 تشغيل محلياً

```bash
git clone https://github.com/cheddine27-cloud/ausar-military.git
cd ausar-military
npm install
cp .env.example .env   # ثم أدخل مفاتيح Supabase
npm run dev
```

## 🔐 متغيرات البيئة

| المتغير | الوصف |
|---|---|
| `VITE_SUPABASE_URL` | رابط مشروع Supabase |
| `VITE_SUPABASE_ANON_KEY` | المفتاح العام (Anon Key) |
| `VITE_APP_NAME` | اسم المنصة (Ausar Military) |
| `VITE_SUPER_ADMIN_USERNAME` / `PASSWORD` | دخول قائد المنصة |

> ⚠️ لا ترفع ملف `.env` إلى GitHub — هو مستثنى في `.gitignore`.

## 📁 البنية الرئيسية

```
src/
├── modules/military/       ← 🪖 وحدة قطاع الجيش (شاشات + صلاحيات + دورة الموافقات)
├── config/institutions/    ← military.ts (المصطلحات + الحصص + البراندينغ العسكري)
├── components/institution-admin/  ← شاشات الحضور/التبريرات/الهيكل/الأجهزة
├── core/                   ← محركات: صلاحيات + تدقيق + تنبيهات + سير أعمال
├── pages/                  ← تسجيل الدخول، لوحة الإدارة، الطالب، لوحة القائد العام
└── lib/                    ← Supabase، التصدير PDF/Excel، QR، الحضور الذكي
student_app_flutter/        ← تطبيق العسكري الدارس (QR الحضور)
supabase/                   ← الـ migrations + الدوال السحابية
```
