# Ausar Military Release Notes — v3.9.5
## QA Phase 2 — End-to-End Attendance Workflows

This release completes Phase 2 of Quality Assurance, checking, validating, and fixing the End-to-End Attendance Workflows.

---

## 🛠️ Verification & Bug Fixes

- **Justification Status Check**: Aligned the client-side status badges to check for `approved` database statuses rather than just `justified`.
- **Justification Badges in Classroom Mode**: Enabled teachers to view student justification status badges (🟢 Excused, 🟡 Pending, 🔴 Unexcused, ⚫ Rejected) in Classroom Mode before starting a session.
- **Manual Parent Notifications**: Checked manual notification triggers, status logs, and history queries.
